# 息刻

休息的「息」，时刻的「刻」。用于早睡提醒、闹钟和倒计时。

电脑和 Android 共用蓝底、米白月弧和暖金色时钟指针；不加文字和细小刻度，保证小图标也能辨认。

- 蓝色：`#315BCE`
- 月弧：`#FFF8EC`
- 指针：`#FFD38A`

矢量源文件：`Assets/Xike.svg`。运行 `scripts/make_icon.py` 可从共同的图形定义重新生成 Windows 多尺寸 ICO、PNG、Android 自适应前景及单色图标。Android 前景留在自适应图标的安全区域中，背景由启动器裁成圆形或圆角方形。

Windows 窗口标题、托盘提示、程序产品名称和 Android 应用名称、前台服务通知统一为「息刻」。程序集、Android 包名和配置路径沿用 TimeGuard，保证现有设置和更新身份连续。

Android 设置使用固定的浅色主题，输入框文字为 `#1B2028`，提示文字为 `#6B7480`，避免系统深色模式导致白底白字；悬浮窗仍使用它自己的深色配色。
