# 数据存储与权限

Android 应用不声明 INTERNET 权限，源码没有接入广告或分析 SDK。闹钟时间、名称、计分规则、悬浮窗位置和倒计时状态保存在本应用的 SharedPreferences 中。卸载或清除应用数据会清除这些设置。

Android 当前允许系统备份（allowBackup=true）。是否备份到云端或迁移到新设备取决于 Android 系统、设备厂商及用户的备份设置；这不等同于应用主动上传数据。演示截图仅使用全新模拟器的预设数据。

Windows 在用户的应用数据目录保存 JSON 配置，并保留恢复备份；文件位置由 desktop/src/AppConfig.cs 定义。Windows 版没有接入广告或分析 SDK。

悬浮窗权限用于跨应用显示挂件；通知权限用于后台状态和闹钟操作；精确闹钟权限用于系统到点唤醒；震动与音频权限用于提醒；全屏提醒权限用于锁屏时显示闹钟操作；开机广播用于恢复调度。拒绝或撤销部分权限可能影响相关功能，设置页会显示权限状态。

报告问题时，建议提供系统版本、设备型号、复现步骤和错误信息；提交日志或配置前先去除个人闹钟名称及其他个人信息。签名私钥和口令不属于源码，不应提交到仓库。
