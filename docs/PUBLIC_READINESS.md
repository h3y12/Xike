# 公开仓库准备记录

2026-10-13：Windows 2.0.3 / Android 1.2.9。

本轮修复 Android 编辑窗口保存旧快照导致一次性闹钟复活、后台新增项或开关被覆盖的问题。保存先加载最新配置，只合并实际编辑的字段；已删除或消费的闹钟不再保存，并提示重新选择。补齐真实设置窗口回归。

桌面真实窗口检查发现：显示主窗口会同步触发 Loaded/Refresh，期间响铃可能已超时清空，原代码仍向响铃窗口传递空状态。本轮在显示后重新检查响铃状态，并避免旧窗口关闭回调清空新的窗口引用。

双端 CI 使用独立 Windows / Linux 作业，检查 Windows 构建、自检和实际闹钟编辑窗口，以及 Android debug 构建、所有单元 / 服务回归测试和 release lint。无需签名私钥；Actions 固定到官方发行提交，默认权限仅 contents:read，不持久化 Git 凭据。

新增双端实际界面效果图及数据存储 / 权限说明。首次上传和后续提交的私钥、口令、缓存与用户配置仍须排除。
