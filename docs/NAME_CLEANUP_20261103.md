# 品牌名称清理与验证（2026-11-03）

适用版本为 Windows 2.0.5 和 Android 1.3.0（24）。

本轮扫描当前仓库、两份独立本地源码、构建与启动脚本、文档、资源文件名、本地快捷方式和交付包。起始扫描在97个已跟踪文件中找到366处旧名称。已将可更改名称统一为息刻 / Xike，包括Windows工程与程序集命名空间、Xike.exe、Xike.ico，Android源码命名空间com.hzy.xike、主题、内部工程名、调试与未签名APK名称，以及CI入口与文档示例。

## 明确保留的兼容标识

| 位置 | 原因 |
| --- | --- |
| Android applicationId `com.hzy.timeguard` | 已发布应用的安装身份，改动会变成另一个App并失去覆盖升级能力；源码命名空间已更名，旧启动图标通过活动别名兼容。 |
| Android LegacyIdentity及设备回归脚本中的原设置文件名、两个通知通道ID | 继续读取既有闹钟、倒计时及用户通知设置。 |
| Windows LegacyIdentity中的旧配置目录和两个进程同步标识 | 首次启动读取旧配置并保存到新的Xike目录，不修改旧文件；与仍在运行的旧版共享单实例锁。 |
| 原正式签名内部别名、证书主体和口令 | 私钥文件已更名xike.jks，密钥内容不变。不可为了清理名称而替换证书或修改口令。 |
| Git历史及历史备份 | 保持历史可恢复；本轮没有重写Git历史，也不改写已保存的旧备份。 |

这些标识是安装身份及兼容数据，不作为当前界面或成品名称展示。未用字符串拆分或编码来伪造零残留。
