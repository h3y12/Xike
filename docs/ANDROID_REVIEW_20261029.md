# Android 1.2.20 发布前审查

范围：自公开初始提交之后的安卓版本地更新，包括铃声选择、连锁响铃、倒计时调度、独立响铃控制卡、悬浮窗边界和开关、分组折叠、布局与脚本。Windows 产品源码未改动。

## 已完成整改

- 倒计时命令取消固定延时，在按钮点击时立即按顺序交给服务，避免离开页面后再启动前台服务。
- 正式打包按版本号命名，并在确认输出后仅保留最近两版；debug 和未签名包保持明确区分。
- 补充自选铃声 URI、文件读取授权和独立响铃控制卡的隐私说明，标明旧版截图与当前界面的差异。
- 复核已实现的到点派送去重与防取消、暂停/重置取消调度、关联闹钟不重复响铃、连锁禁用稍后提醒、页面与控制卡互斥、横屏边界及分组状态同步。

## 验证

本地 208 项单元、服务及页面测试全部通过，lintRelease 无错误；原签名正式构建通过，APK 内许可文件与仓库一致。补充真实 Android 布局测量，检查双行按钮等高、等宽和边缘对齐；补充页面离开前立即发送命令的检查。

准备上传的源码及新文件经过常见凭证格式与敏感文件名检查，未命中；私钥、签名配置、用户数据、缓存和安装包不进入源码提交。安装包通过 Releases 分发。双端 CI 在上传提交后运行，检查 Windows 构建与回归，以及 Android 构建、全量测试和 lint。

此前本批功能的 Android 15 模拟器验证已覆盖：健康分悬浮窗服务未运行、全屏权限禁用时，系统仍能派发倒计时并显示可直接停止的控制卡；全屏横屏可拖至屏幕顶端。此轮未连接用户 iQOO，整夜锁屏、省电和重启仍以真机验收为准。
