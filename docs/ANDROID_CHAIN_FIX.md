# Android 1.2.8：连锁闹钟设置操作

日期：2026-10-13，versionCode 11。

App 闹钟列表的开关作用于整组：关闭任意成员会关闭所有同 chainId 的成员，开启亦然；所有成员的开关和颜色同步刷新。连锁成员的编辑窗口显示“删除整组”，删除同组所有成员并重新调度系统闹钟。普通闹钟和其他组不受影响。

响铃时的“停止”仍只停止当前响铃，后续成员继续按各自钟点提醒。

设置操作读取最新配置再修改，避免覆盖后台已经消费的闹钟；即使编辑窗口打开期间当前成员已经被消费，删除操作仍会移除其余同组成员。
